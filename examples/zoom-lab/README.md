# Zoom Motion Lab

A comparison surface for the ZoomStage v2 camera language. It demonstrates:

- Glide, Arc, Dolly, Orbit and Focus trajectories on the same route.
- Automatic duration and perceptual logarithmic zoom.
- Frameless, glass, circular, pill and custom polygon surfaces.
- A camera target that is independent from its visible scene.
- Departing, arriving and settled lifecycle states.
- A keyboard-accessible world overview where selecting any frame focuses it
  with that frame's own trajectory.

Serve the repository with `python server.py`, then open
`http://localhost:8000/examples/zoom-lab/`.
