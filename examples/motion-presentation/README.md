# Motion Presentation

A four-scene presentation built with `fluxaway-motion` and normal FluxaWay
components — no ZoomStage. It demonstrates the Macromedia Flash mental model:

- one master timeline with scene labels and frame scripts;
- `play()`, `stop()`, `gotoAndPlay()` and `seek()` playback controls;
- overlapping scene symbols on a fixed stage;
- a nested looping MovieClip with its own `useTimeline`;
- keyboard navigation and a timeline scrubber;
- a responsive 16:9 desktop stage recomposed for narrow screens.

Serve the repository root and open `/examples/motion-presentation/`.
