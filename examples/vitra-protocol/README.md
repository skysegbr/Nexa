# VITRA Protocol

An original six-scene material narrative built to exercise the current
`docs/AI_SPEC.md` guidance in a production-shaped example.

- ZoomStage v2 trajectories: Glide, Arc, Dolly, Orbit and Focus.
- Circle, pill, glass, frameless and custom-clipped surfaces.
- An independent camera target on the final scene.
- Settlement-driven FluxaWay Motion entrances: incoming content never blanks
  while the camera is travelling.
- Small, closed-loop motion tracks only; no full-frame transforms.
- Seven original photographic plates with consistent dark-studio lighting,
  physical glass and steel surfaces, and a restrained red signal.
- Responsive image crops with HTML copy kept outside the artwork, so text stays
  sharp and accessible at every camera scale.
- A clickable and keyboard-accessible Fit overview.

Serve the repository with `python server.py`, then open
`http://localhost:8000/examples/vitra-protocol/`.
